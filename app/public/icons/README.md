# Ecosystem icons

These SVGs are copied without modification from [Simple Icons](https://github.com/simple-icons/simple-icons), commit `98820a4dc8c363ca72fa2c0d294ea4a0a9bba75d`.

The Rust mark represents Cargo. The other files represent npm, Dart, Python, Go, Deno, and GitHub. Brand names and marks belong to their respective owners. Simple Icons distributes its collection under [CC0](https://github.com/simple-icons/simple-icons/blob/98820a4dc8c363ca72fa2c0d294ea4a0a9bba75d/LICENSE.md).

The website serves these files locally and applies the current text color through a CSS mask. Each icon is decorative beside a visible brand name.
