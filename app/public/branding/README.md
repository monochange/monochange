# monochange website identity

The active identity is the selected flowing three-part mark and custom lowercase wordmark. Canonical SVG sources and export instructions live in [assets/brand](../../../assets/brand/README.md).

- `mark.svg`: transparent square mark for navigation and compact placements.
- `logo.svg` and `logo-dark.svg`: full logo on light and dark surfaces.
- `social.png`: website sharing artwork.

Browser icons and the web manifest live one directory above this one. Keep them synchronized with the canonical sources. The two files under `logos/` are historical concepts and are not used by the website.
