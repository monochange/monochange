# What's new on monochange.dev

User-facing website release notes generated by monochange.

## 0.2.0

### Changed

#### Use the website's book address for new documentation links

_Owner:_ [@ifiokjr](https://github.com/ifiokjr) · _Review:_ [PR #752](https://github.com/monochange/monochange/pull/752)

> The website's documentation destination is now `/book` on `monochange.dev`.

Point new documentation links and bookmarks to `https://monochange.dev/book`. Existing `/docs` links redirect to the matching chapter. The standalone book remains available, with a link back to the website.

For example, update a documentation link in Markdown:

```markdown
[Read the book](https://monochange.dev/book)
```

### New

- **Read the monochange book without leaving the website.** The book now lives at `monochange.dev/book`, with the same navigation, typography, and light and dark themes as the rest of the website. Follow chapter links, copy highlighted code examples, and return to the homepage at any time. The homepage now uses `monochange preview`, and ecosystem marks make supported tools easier to recognize. _Owner:_ [@ifiokjr](https://github.com/ifiokjr) · _Review:_ [PR #752](https://github.com/monochange/monochange/pull/752)
- **Follow what's new on monochange.dev.** Read the website's release notes on the new What's new page. Website updates now have their own versions, separate from the CLI, and approved releases deploy automatically. _Owner:_ [@ifiokjr](https://github.com/ifiokjr) · _Review:_ [PR #751](https://github.com/monochange/monochange/pull/751)
