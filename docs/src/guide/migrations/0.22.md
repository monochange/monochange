# Upgrading to 0.22

Existing CLI invocations and TOML configurations need no changes. GitHub release bodies now shorten oversized notes automatically, with a link to the complete changelog.

## Rust release settings

Rust callers constructing every field of `monochange_core::ProviderReleaseSettings` must add `max_body_chars: None` for the default cap, or `Some(limit)` for a smaller cap. Callers using struct update syntax with `Default` continue to compile:

```rust
use monochange_core::ProviderReleaseSettings;

let settings = ProviderReleaseSettings {
    max_body_chars: None,
    ..Default::default()
};
```

The default GitHub release cap is 125,000 characters. Larger configured values are clamped to that limit. Metadata stays enabled; only complete entries that fit are shown, followed by a changelog link when entries are omitted.
