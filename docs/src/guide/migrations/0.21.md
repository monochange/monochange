# Upgrading to 0.21

Version 0.21 adds Swift, CocoaPods, and Gradle packages. Existing CLI configurations need no changes. Rust callers constructing configuration or registry endpoint structs must initialize the new fields.

## Workspace configuration struct literals

_Affects: Rust code constructing `monochange_core::WorkspaceConfiguration` directly._

Add these fields to existing struct literals:

```rust
swift: EcosystemSettings::default(),
cocoapods: EcosystemSettings::default(),
gradle: EcosystemSettings::default(),
```

Import `EcosystemSettings` from `monochange_core`. Previously serialized workspace configurations remain readable; missing native ecosystem settings default automatically.

## Registry endpoint struct literals

_Affects: Rust code constructing `monochange_publish::RegistryEndpoints` directly._

Prefer constructing endpoints with `RegistryEndpoints::from_env()` and then overriding the fields your caller needs. Explicit struct literals need these additional fields:

```rust
cocoapods_trunk_api: "https://trunk.cocoapods.org/api/v1".to_string(),
maven_central: "https://repo1.maven.org/maven2".to_string(),
```

The environment constructor reads `MONOCHANGE_COCOAPODS_TRUNK_API_URL` and `MONOCHANGE_MAVEN_CENTRAL_URL` when set, otherwise using the public registry defaults shown above.

See the [ecosystem guide](../ecosystems.md) to add native packages or configure their versioned files and publication commands.
