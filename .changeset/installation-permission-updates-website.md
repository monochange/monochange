# See which accounts need to approve new GitHub access

When monochange asks GitHub for more access, the dashboard now lists each connected account that hasn't approved the request yet, with the access it is missing and a **Review on GitHub** link where an owner of that account accepts it. Until then, monochange keeps the access the account already approved. You don't need to sign in again.

The GitHub App guide now explains each permission the app requests and what happens when the app asks for more.
