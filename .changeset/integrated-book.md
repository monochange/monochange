# Read the monochange book without leaving the website

The book now lives at `monochange.dev/book`, with the same navigation, typography, and light and dark themes as the rest of the website. Follow chapter links, copy highlighted code examples, and return to the homepage at any time. The homepage now uses `monochange preview`, and ecosystem marks make supported tools easier to recognize.
