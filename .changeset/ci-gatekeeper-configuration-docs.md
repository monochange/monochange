# Document `[ci]` configuration for the `monochange ci` gatekeeper

The configuration guide now documents the `[ci]` table: provider settings, `ai_can_skip`, unconditional and ignored paths, `[ci.jobs.<id>]` roots, paths and `always`, the `--on-error run-all` fail-safe, and a recommended gate workflow. The published JSON schemas include the new section.
