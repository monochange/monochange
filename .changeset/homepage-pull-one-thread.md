# Try a release plan right on the homepage

The homepage now opens with a live release preview. Pick the package that changed and whether it is a patch, minor, or major change, then watch the changeset update and the plan show every package that releases, including dependents that follow with a patch release. The rest of the page walks through the three commands behind it, the supported ecosystems, the shared GitHub sign-in, and the fact that monochange is free.
