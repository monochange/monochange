# Collect feedback inside your apps and review agent plans

Project maintainers can connect websites, React Native apps, and Flutter apps to their feedback console. Customers can describe a bug or idea, discover similar requests to upvote, discuss details, and follow progress using their existing app account.

Connect an agent on your own machine or server to prepare implementation plans. Choose requests yourself or enable automatic planning for new feature requests. Review each complete plan, request changes, reject it, or approve it for implementation. Approval opens the path to a draft pull request; it never merges the change automatically.
