# Open projects with the same GitHub account

> Your workspace now opens at `/projects`.

monochange projects has its own workspace navigation while keeping the same GitHub account as the website. Open workspace returns you to projects after sign-in. Use Connect repositories to manage repository access on the website. Existing project and feedback bookmarks continue to point to their project through compatibility redirects.

Update your bookmarks when convenient:

```text
Previous bookmark: /dashboard/your-account/projects/your-project
New bookmark:      /projects/your-account/projects/your-project
```

Review connected devices and revoke their access in Account and devices. Native installations require an updated app binary to support browser sign-in.
