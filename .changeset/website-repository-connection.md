# Connect repositories from your workspace

When the deployment has a configured GitHub App, your dashboard links to that app's verified GitHub installation page. Choose all repositories or selected repositories on GitHub, then return to the dashboard. If repository connection is unavailable, the workspace explains the missing setup instead of implying that signing in connected your repositories.

First-time installations now appear even when installation finishes before website sign-in. Repository selection, suspension and removal stay isolated to the correct installation. This connection flow does not enable hosted release automation.
