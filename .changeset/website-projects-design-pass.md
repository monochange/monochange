# Make the website and projects feel like one place

When you're signed in, the header is calmer. Connect repositories, Account and devices, and Sign out are now together in one account menu. That menu is the same on the website and in your projects, and it works with a keyboard and screen readers. On a phone, the menu groups the same account links under your name.

Projects pages now end with the same footer as the rest of the website. Long organization and project names wrap instead of filling the screen. Projects appear as matching cards on your workspace and on each organization page, and "New project" sits at the end of that grid. A project with no repositories now tells you where to add them.

Install commands and code samples in the book are now readable in the dark theme. Headings, sections and status labels share one size and spacing across both themes.
